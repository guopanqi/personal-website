# 系统作用判断候选

假设：在类型与摩擦判断前要求解释机制在体验中的具体作用，并为负面限制提供实际要求的证据，能减少将叙事中的战斗、养成误判为外部成本的错误；这种改善应出现在实际因果解释而非仅分数上。

改动：去掉将成长与外围包装并列的暗示；新增两段机制作用与摩擦证据约束；在外部核验目标中加入系统联系。Taste 保持工作区原样。候选不包含任何游戏名称、预期分数或例外条款。

预期收益：故事/人物通过日程、资源、能力、战斗等活动被体验时，能解释其作用，不要求结构创新或双向分支作为叙事价值的门槛。

可能退化：把题材或少量剧情误当成整合；弱化重复刷取、操作负担和硬排除项；证据不明时补写机制；因谨慎而增加待确认。逐例审阅这些风险。

证伪条件：候选仍按类型自动列摩擦、只有新术语没有具体解释，或在其他案例中丢失真实限制/编造系统联系，则该候选不足以解决问题。提高《活侠传》的分数不构成单独成功依据。

本轮只运行原有33例，无新增测试案例。标题输入依赖模型记忆，不能验证联网核验和真实玩法理解，也没有独立保留集。
