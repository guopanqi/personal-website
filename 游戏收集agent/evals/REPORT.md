# 游戏判断评估：按推荐覆盖重新评估

**最终决定：本轮不采用候选 Taste/Skill，保留当前正式标准。** 实验未显示足够明确、稳定的收益，不为表达更详细而增加正式规则。候选及原始输出仅作为历史实验记录；评估工具和修正后的推荐覆盖口径保留，假想案例不加入正式测试集。

用户明确：暂不加入假想或其他新增案例，继续使用原33例；应该推荐却没推荐是严重错误，推荐与必须推荐之间浮动通常可以接受。原测试集及正式Taste/Skill未改变。

主要问题在评估口径。原测试集本来就提示“推荐门槛优先，强度次之”，此前报告却把完整标签一致率放在首位，并把部分强度变化称为退化，放大了主观优先级分歧。现在保留三种原标签作为历史观察，但不要求两种正向强度精确匹配。

## 当前规则

- 推荐覆盖：金标准的推荐、必须推荐统一视为应该推荐；模型判为不推荐是严重漏推荐。
- 推荐强度浮动：推荐与必须推荐之间变化只记录，不自动算错误或退化；分数变化同样不单独证明退化。
- 待确认：信息不足不等于明确拒绝，但也没有完成推荐覆盖，单列数量。
- 误推荐：不推荐被推荐单列，需看是否误解玩法、忽略偏好，或有证据支持重新评价。
- 语义质量：错误机制、虚构证据、泛泛说明及个人兴趣与研究混淆仍可构成实质问题，必须指出具体依据。判断理由变差与推荐强度变化分开评价。

|指标|基线|第一版|第二版|

两版候选都保留25/25个应推荐案例，没有明确漏推荐。DREDGE从必须推荐到推荐、RimWorld从推荐到必须推荐都不再仅凭标签视为退化。基线有1个正向案例因资料不足尚未完成推荐覆盖。

第一版《书店增量》在主循环不明时给推荐，属于实际误推荐与证据问题；第二版恢复信息不足。第二版逐款依据较具体，是值得审阅的收益。负向案例多仍未知，不能声称雷区判断已全面验证。此前独立模型给出的“退化”计数使用旧口径，不直接沿用；模型输出原文保留供复查。

**正向推荐强度浮动不是否决理由；本轮不采用的原因是尚无足够明确的改善证据。** 不围绕必须推荐/推荐的精确标签调参，也不为了匹配率压制诚实的不确定性。用户的优先级可以随情境和实际体验变化，不把一时强度当作永久固定答案。
